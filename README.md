# FESTIVO

FESTIVO is a multilingual event-equipment marketplace built as a responsive single-page web application. The interface is available in Uzbek (default), Russian, and English, with the selected language stored locally.

## Run locally

```sh
npm install
npm run dev
```

## Verify

```sh
npm test
npm run build
```

The demo keeps the cart, customer profile, bookings, vendor listings, and listing statuses in browser `localStorage`; there is no backend service configured in this repository.
